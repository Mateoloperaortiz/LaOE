# Evidencia y propuestas de diseño

- `mocks/decision/`: propuestas conceptuales de navegación con sus prompts y limitaciones. No son interfaces implementadas ni aprobadas.
- `committees-direction.md` y `surfaces/`: dirección y contrato del directorio de comités.
- `review/comites/`, `review/podio/` y `review/gt-gap/`: capturas de revisión con datos sintéticos; los informes conservan el alcance y los resultados de cada revisión local.

Estos archivos documentan el trabajo y no son recursos servidos por la aplicación. Las rutas absolutas de las metadata indican el origen local de las referencias. El estado temporal de `questions/` (PID, puerto y heartbeat) se conserva fuera de Git.

La publicación y las verificaciones posteriores se registran en `docs/09-roadmap.md` y `docs/15-runbook.md`; una captura o un informe local no acredita un despliegue.
